## Run locally

### Requirements

- Node.js 18 or newer
- npm

### Setup

```bash
git clone https://github.com/anushka-2711/anushka-singh-portfolio.git
cd anushka-singh-portfolio
npm install
npm run dev
```

Open the local URL shown by Vite in your browser.

## Validate and build

```bash
npm run build
npm run preview
```

The production build is generated in `dist/`. The `dist/` directory and `node_modules/` are intentionally ignored because they are generated locally and should not be committed.

## Contact behavior

The contact form uses a `mailto:` flow. When a visitor submits it, their default email application opens with the recipient, subject, and message already prepared for review before sending.

## Deployment

The project is ready for Vercel deployment. Connect the GitHub repository to Vercel and use the default Vite settings:

```text
Build command: npm run build
Output directory: dist
```
